# MeetMind — Feature pillars

## Core engine
- Turns transcript or topic into minutes: summary, decisions, action items
- Auto-assigns owners and due dates where the input supports it
- Exports bullets, email, Slack plus a follow-up draft

## Workflow & output
- Teams get consistent notes without a dedicated scribe
- Actionable output that lands where work already happens
- Seconds from input to structured minutes

## Trust & control
- Decision-support for meeting notes — not a recording compliance product
- No fabricated attendance or engagement metrics
- Demo mode without a live API key
